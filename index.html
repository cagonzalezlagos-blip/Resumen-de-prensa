Fuentes y búsqueda automática

Esta versión incorpora el flujo completo y una capa de conexión para búsqueda automática. Cuando se publique con un servicio de búsqueda/backend, el botón “Buscar noticias” podrá importar automáticamente resultados y clasificarlos. Mientras no exista ese servicio, la aplicación conserva todas las funciones de revisión y generación manual.
